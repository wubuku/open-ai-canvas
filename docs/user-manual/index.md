# 影策用户手册

影策 Web UI 的使用手册分为两部分：

- [创作台用户手册](creator/)：面向普通创作者，覆盖自由画布、图片/视频/文本/Agent 创作、资产、技能、插件、灵感、短剧项目、积分和个人设置。
- 管理员后台手册：尚未纳入当前版本，完成后会在这里增加独立入口。

## 如何阅读

按“目标 → 步骤 → 结果”的顺序阅读每篇任务指南。正文中的截图对应当前开发环境的真实界面，截图下方会解释你应当观察到的控件、状态或结果；截图本身不替代操作步骤。

视频任务可能比前端等待时间更长。看到超时提示时，先到[创作历史](creator/10-tasks/browse-tasks.md)确认任务最终状态，再决定是否重试，避免重复提交和重复扣费。
