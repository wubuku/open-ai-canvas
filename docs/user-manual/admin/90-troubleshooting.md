# 常见问题与排障

## 页面显示前台模型暂未开放

**现象**：`/admin/models`显示“前台模型暂未开放”。

**原因**：用户模型来源或前台目录功能开关处于关闭状态。

**处理**：到[功能开放](10-tasks/configure-product-experience.md)查看开关和模型来源。不要把空页面当作前端加载失败；开启前先评估现有用户入口和模型权限。

## 视频生成前端先超时，但任务可能成功

**现象**：创作台提示等待视频生成超时，后台请求或上游仍可能在执行。

**处理顺序**：

1. 在创作历史确认任务状态、任务 ID和是否已有结果。
2. 在请求明细查看阶段、渠道、耗时和错误摘要。
3. 如果任务仍在运行，不要立即重复提交；等待最终状态或按既定恢复流程处理。
4. 如果后台任务也超时，再检查[资源与策略](10-tasks/configure-runtime-policy.md)中的视频任务超时、Worker 并发、渠道请求超时和熔断。
5. 记录前端等待超时与后台任务超时的时间点，分别交给前端和后端定位。

提高后台视频任务超时不会自动延长浏览器等待时间，也不能单独证明上游供应商会成功。

## 支付显示已付但积分未到账

先在支付页查单和对账，再核对积分账本。按幂等规则补发，不能直接重复人工加分。平台不提供支付退款，退款争议需回到支付渠道和业务流程。

## 资源删除前无法确认是否安全

检查项目、画布、任务和其他业务引用。只有确认无引用并准备回收方案后才考虑删除；物理删除失败时保留资源记录，避免出现“记录没了、对象还在”或反向的悬空引用。

## SMTP 保存后仍无法找回密码

检查账户邮件开关、SMTP连通性、发件域名白名单和服务端日志。白名单只影响新用户注册，不影响已有账号找回密码。不要在工单中粘贴 SMTP 密码。

## 保存按钮不可用

页面可能在当前没有未保存修改，或当前功能依赖其他开关。先刷新状态，再核对字段是否发生变化和是否满足前置条件；不要通过重复点击或修改无关字段强行触发保存。

## 系统更新按钮可见但不能执行

检查 Host Updater、Unix Socket、备份和当前部署模式。按钮可见只表示页面提供入口，不代表当前部署具备在线更新能力。没有回退演练时不要开始更新。

## 本手册能证明什么

本轮真实浏览器回走确认了管理员路由、主要控件、空状态、筛选和只读展示。没有执行真实支付、退款、关单、积分调账、兑换码生成、用户停用、权限修改、资源删除、插件上传/卸载、密钥保存、系统更新或回退；也没有做跨标签页锁竞争、跨设备同步、生产性能压测或完整 Agent 运行链路验收。
