# 后台概念与权限

## 配置来源不是同一个状态

后台常见的“系统默认”“管理员配置”“已启用”“已配置”描述的是不同维度。系统默认表示来源，已启用表示开关，已配置表示服务端保存过凭据或参数。看到“已配置”仍需通过隔离请求验证真实可用性。

## 页面状态与运行状态分开看

运行总览、请求明细、任务历史、资源记录和本地缓存的生命周期不同。页面加载成功只能证明读取路径可用，不能证明任务已成功、资源已物化或用户已收到通知。

## 超时分层

管理员后台的任务超时限制后台任务最长执行时间；渠道请求超时限制一次出站请求；熔断持续时间限制失败后的保护窗口；浏览器等待超时则由前端等待策略决定。它们需要分别观测和配置。

尤其是视频生成：前端可能先显示等待超时，而后台任务仍在执行。先查询创作历史、请求明细和上游任务身份，再决定是否调整后台策略或修复前端等待逻辑。重复提交可能重复扣费或制造重复任务。

## 读、写和破坏性动作

- 读：刷新、筛选、查看详情、预览、下载、检查状态。
- 写：保存配置、启用版本、发布公告、创建批次、调整额度、恢复任务。
- 破坏性或高风险：删除资源、停用用户、卸载插件、写入密钥、开始更新、版本回退。

管理员权限意味着可以看到入口，不意味着可以跳过审批。页面按钮、API权限、服务端业务校验和审计记录应共同形成边界。

## Agent 三层能力

在排查 Agent 相关功能时，区分“工具定义存在”“注册表中存在”和“当前主执行链已实例化并可调用”。后台页面显示入口或配置项，不足以证明完整 Agent 运行链路已经通过验收。
