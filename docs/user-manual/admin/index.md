# 管理员后台

管理员后台用于观察平台运行状态、管理模型和资源、处理用户运营事务，并配置站点与运行策略。

建议第一次使用时按这个顺序阅读：

1. 先看[快速上手](00-quickstart.md)，确认自己的权限和变更窗口。
2. 用[运行总览、请求明细和系统性能](10-tasks/monitor-and-troubleshoot.md)完成一次只读巡检。
3. 按业务需要阅读模型、用户、计费或平台配置章节。
4. 修改配置前阅读[后台概念与权限](30-concepts.md)和对应章节的“风险边界”。

后台导航按四组组织：**监控与排查**、**模型与资源**、**用户与运营**、**平台配置**。页面之间共享当前管理员账号和服务端配置，但每次保存仍应单独核对影响范围。

![管理员后台运行总览](screenshots/admin-overview.png)

运行总览会显示活跃用户、生成任务、服务质量、P95 请求耗时、当前排队和成本覆盖等指标。它适合做第一层健康检查；要定位单个失败请求，请继续查看请求明细。
