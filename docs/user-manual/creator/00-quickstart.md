# 快速上手

## 你将学会
在 5 分钟内完成影策的第一步创作：打开创作台、选择创作模式、用提示词生成一张图片或一段视频。

## 前置条件
- 已注册影策账号并登录。如果还没有账号，请先完成[注册与登录](10-tasks/register-and-login.md)。
- 账号有可用积分（新用户默认有赠送积分，侧栏"影策加油站"每日可再领取）。

## 从首页开始创作

1. 打开影策后默认进入创作页（侧栏第一项 **创作**）。
2. 在“创作模式”栏选择你要生成的内容类型：**视频**、**图片**、**文本** 或 **Agent**。页面会保留当前会话的模式选择；以当前显示的选中状态为准。
3. 在输入框中描述你想创作的画面或故事，例如"一只橘猫坐在窗台上看雨"。
4. 需要时可以：
   - 点击 **参考内容** 上传参考图，让生成结果贴近你的风格；
   - 点击模型名切换不同模型；
   - 点击比例按钮（如 **1:1**）调整输出比例。
5. 点击 **开始创作**，等待结果区域更新。视频任务可能比前端等待时间更长，遇到超时提示时先去[创作历史](10-tasks/browse-tasks.md)确认任务状态。
6. 生成结果会出现在当前对话区域。图片可右键另存或进入 **资产** 查看；视频可在 **创作历史** 中找到。

## 从自由画布开始创作

如果你需要更灵活的组织方式（比如同时管理角色、场景、分镜和生成结果），可以使用自由画布：

1. 点击侧栏 **自由画布**。
2. 点击 **新建画布**，或打开一个已有画布。
3. 在画布内点击底部工具栏的 **添加节点**，选择 **文本**、**图片**、**视频** 等节点类型。
4. 通过节点两侧的连接点将节点串联，形成创作流程。
5. 在视频/图片节点中输入提示词并引用上游节点（用 `@节点名`），点击生成。

详细操作请阅读[使用自由画布](10-tasks/use-canvas.md)。
