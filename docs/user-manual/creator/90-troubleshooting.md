# 常见问题

## 视频任务显示超时，但可能仍会成功

视频生成耗时较长。前端等待超时后，先打开 **创作历史**，筛选 **运行中** 和 **已完成**，确认任务最终状态；不要立即重新提交，以免产生重复任务或重复扣费。

## 生成结果没有出现在画布

先确认节点仍存在、任务没有被替换，再打开画布左侧 **历史** 或全局 **创作历史** 查看任务结果。刷新页面后仍无结果时，记录任务详情中的错误信息。

## 素材上传失败

检查文件格式、大小、账号剩余容量和网络。上传失败时不要连续重复提交；先刷新素材库确认是否已经生成了一条素材记录。

## 插件或技能不可用

确认插件状态是“已启用”，技能是否已经加入 **我的技能**。管理员停用的插件需要联系管理员处理。

## 积分与任务状态不一致

同时查看积分中心的 **积分消耗历史** 和创作历史的任务详情。失败任务若显示“消费退款”，不要再次申请退款。
