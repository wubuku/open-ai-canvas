# 注册与登录

## 适用角色
所有新用户和需要切换账号的用户。

## 目标
注册影策账号并登录，进入创作工作台。

## 步骤

### 注册新账号

1. 打开影策，系统自动跳转到登录页。截图如下：

![影策登录页](../screenshots/login-page.png)

2. 点击 **注册** 或 **立即注册** 入口。
3. 填写邮箱、密码和验证码（如果需要）。
4. 提交后即可登录。

### 登录已有账号

1. 打开影策，在登录页输入邮箱和密码。
2. 点击登录按钮。
3. 登录成功后进入创作工作台首页。

### 忘记密码

1. 在登录页点击 **忘记密码**。
2. 输入注册邮箱。
3. 按照邮件或页面提示完成重置。

## 成功判据
登录后侧栏出现 **创作**、**灵感**、**短剧 Agent**、**自由画布** 等入口，顶部显示积分余额。

## 排障
- **验证码收不到**：检查垃圾邮件文件夹，或稍后再试。
- **登录后跳回登录页**：清除浏览器 Cookie 后重试。
