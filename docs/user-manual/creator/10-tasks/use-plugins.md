# 查看和使用插件

## 适用角色
需要扩展模型协议、媒体处理或工作流能力的创作者。

## 目标
在插件中心按类别和状态查找插件，阅读能力说明，确认插件是否已启用。

## 步骤

1. 从侧栏点击 **插件**。

![插件中心](../screenshots/plugins-page.png)

页面按 **文本协议**、**图片协议**、**视频协议**、**音频协议**、**支付协议** 和 **应用插件**分类。顶部搜索框支持按名称、描述或作者查找，状态和来源下拉框可进一步筛选。

2. 点击插件卡片上的 **查看…文档**，先看它提供的能力、使用面板和当前状态。
3. 已启用的插件会显示“已启用”；由管理员停用的插件会显示“管理员已停用”，普通创作者不能自行打开。
4. 插件声明为画布节点时，到自由画布的 **添加节点** 面板中查找相应节点；声明为工作台时，按插件文档进入对应入口。

## 成功判据
插件卡片显示已启用，且对应节点或工作台入口出现在创作台中。

## 安全边界
插件可能调用模型、素材或支付协议。执行任何会产生费用、外部通知或数据写入的能力前，先阅读插件文档中的确认和权限说明。
