# 用提示词生成图片

## 适用角色
创作者。

## 目标
从首页图片模式提交一次图片生成请求，并确认结果已返回。

## 步骤

1. 进入创作页，点击 **图片生成**。

![图片生成模式](../screenshots/create-image-mode.png)

2. 在提示词框输入画面描述，例如“深蓝色蛋白酸奶瓶悬浮于旋转的乳白色液体漩涡中”。
3. 需要参考图时点击 **添加更多参考内容**，上传文件后确认参考内容轨道中出现缩略项。
4. 点击 **选择图片模型**，选择当前账号可用的模型；点击 **生成设置：1:1** 调整比例。
5. 确认发送按钮显示本次积分消耗，再点击 **开始创作**。

提交按钮只有在输入框有内容且模型可用时才会启用。图片生成通常比视频快，但仍应等待结果区域出现完成状态。

## 成功判据
真实提交后，当前创作区出现图片结果，且素材库或创作历史中可以找到对应记录。本次手册审计只走到提交前的输入、模型和画幅检查，没有触发真实图片生成或消耗积分。

## 取消/恢复
生成请求提交后不要重复点击发送。失败时先查看错误信息，再修改提示词、模型或参考素材后重试。
