## 已接受限制

- 没有启动真实模型生成、支付、删除、发布、权限变更或外部通知；这些动作需要隔离账号、低成本模型和单独授权。
- 自由画布的新增节点、连线、撤销/重做持久化、导入导出和分享发布没有在本轮触发写入；手册已把界面入口与未验证边界分开描述。
- 视频等待超时的处理说明来自当前前端状态和创作历史界面；本轮没有人为制造上游延迟，也没有把一次超时模拟当作生产验收。
- 没有做跨标签页真实锁竞争、跨设备同步、真实生产性能压测或完整 Agent 运行链路验收。
