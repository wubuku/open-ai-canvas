# 创作台参考

## 一级入口

| 入口 | 用途 |
|---|---|
| 创作 | 图片、视频、文本和 Agent 模式 |
| 灵感 | 浏览并复用提示词 |
| 短剧 Agent | 从一句话故事组织章节和工作流 |
| 自由画布 | 用节点和连线组织创作 |
| 资产 | 管理账号素材 |
| 技能 | 发现并调用技能 |
| 插件 | 管理扩展能力 |
| 创作历史 | 查看任务状态和结果 |

## 生成状态

- **运行中**：任务已经提交，结果尚未完成。
- **已完成**：结果可查看或下载。
- **失败**：任务未完成，先看详情中的错误，再决定是否重试。
- **已取消**：任务被取消或被系统终止。

视频任务的界面超时不一定等于上游任务失败，最终状态以创作历史为准。

## 额度和资源

积分中心记录充值、兑换、模型调用、冻结和退款。资产库记录文件类型、大小、来源和业务分类；对象存储容量与积分额度是两套独立限制。
